ตั้งค่าการเชื่อมต่อ Google Sheets & Apps Script

เมื่อเปิดใช้งานเว็บแอปผ่าน GitHub Pages (bansandab.github.io/Judson/) จำเป็นต้องระบุ URL เว็บแอปของ Google Apps Script เพื่อให้สามารถอ่าน-เขียนข้อมูลลงชีต และส่งแจ้งเตือนเข้ากลุ่ม LINE ได้จริงครับ

คัดลอกจาก Google Apps Script: เมนู ทำให้ใช้งานได้ (Deploy) > จัดการการทำให้ใช้งานได้ (Manage deployments) > URL ของเว็บแอป
พร้อมทดสอบการเชื่อมต่อ
ขั้นตอนการนำ URL มาใส่ (ทำครั้งเดียว):
  1. เปิดแท็บ Google Apps Script โครงการ "ระบบจัดสอนแทน V1.2"
  2. กดปุ่มสีน้ำเงิน "ทำให้ใช้งานได้ (Deploy)" มุมขวาบน ➔ เลือก "จัดการการทำให้ใช้งานได้ (Manage deployments)"
  3. กดที่ไอคอนรูปดินสอ (แก้ไข) ➔ เลือกเวอร์ชันเป็น "เวอร์ชันใหม่ (New version)"
  4. ตรวจสอบว่า "ผู้มีสิทธิ์เข้าถึง (Who has access)" เป็น "ทุกคน (Anyone)"
  5. กด "ทำให้ใช้งานได้ (Deploy)" แล้วคัดลอก URL ของเว็บแอป (ที่ลงท้ายด้วย /exec)
  6. นำ URL มาวางในช่องด้านบนนี้ แล้วกด "ทดสอบและบันทึก"
